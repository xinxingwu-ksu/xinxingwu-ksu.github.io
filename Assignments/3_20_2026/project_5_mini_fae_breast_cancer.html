Assignment

Detailed Assignment Description

Goal. Create a two-stage experiment that approximates the paper’s intuition in a classroom-friendly way.

Tasks

  1. Load datasets/breast_cancer.csv and standardize the features.
  2. Train a scoring autoencoder with a one-to-one nonnegative feature weight layer.
  3. Rank features by learned score.
  4. Create three subsets of equal size:
    • top-k features
    • next-k features
    • random-k features
  5. For each subset, train a small local reconstructor that predicts the full feature vector.
  6. For each subset, also train a downstream classifier and report test accuracy.
  7. Discuss whether the top-k subset is clearly better and what that suggests about learned feature importance.

What students should learn

  • The difference between global scoring and subset evaluation
  • Why a feature subset should be tested, not just ranked
  • Why different subsets can still contain useful information

Reference Answer / Solution

import numpy as np
import pandas as pd
import tensorflow as tf
from tensorflow import keras
from tensorflow.keras import layers
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression, LinearRegression
from sklearn.metrics import accuracy_score, mean_squared_error

# ---------------------------------------------------
# 1) Load local dataset
# ---------------------------------------------------
df = pd.read_csv("datasets/breast_cancer.csv")
X = df.drop(columns=["target"]).values.astype("float32")
y = df["target"].values
feature_names = df.drop(columns=["target"]).columns.to_list()

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.2, random_state=7, stratify=y
)

scaler = StandardScaler()
X_train = scaler.fit_transform(X_train).astype("float32")
X_test = scaler.transform(X_test).astype("float32")

n_features = X_train.shape[1]
top_k = 10

# ---------------------------------------------------
# 2) Stage A: learn global feature scores with a scoring autoencoder
# ---------------------------------------------------
class FeatureScaler(layers.Layer):
    def __init__(self, l1_strength=1e-3, **kwargs):
        super().__init__(**kwargs)
        self.l1_strength = l1_strength

    def build(self, input_shape):
        self.w = self.add_weight(
            shape=(input_shape[-1],),
            initializer="ones",
            trainable=True,
            constraint=keras.constraints.NonNeg(),
            name="feature_scores"
        )

    def call(self, inputs):
        self.add_loss(self.l1_strength * tf.reduce_sum(self.w))
        return inputs * self.w

inputs = keras.Input(shape=(n_features,))
scaled = FeatureScaler(l1_strength=1e-3, name="feature_scaler")(inputs)
x = layers.Dense(24, activation="relu")(scaled)
latent = layers.Dense(12, activation="relu")(x)
x = layers.Dense(24, activation="relu")(latent)
recon = layers.Dense(n_features, activation="linear")(x)

global_model = keras.Model(inputs, recon)
global_model.compile(optimizer="adam", loss="mse")
global_model.fit(
    X_train, X_train,
    validation_split=0.1,
    epochs=200,
    batch_size=16,
    verbose=0
)

scores = global_model.get_layer("feature_scaler").get_weights()[0]
ranking = pd.DataFrame({"feature": feature_names, "score": scores}).sort_values(
    "score", ascending=False
)

top_idx = ranking.index[:top_k].tolist()
next_idx = ranking.index[top_k:2*top_k].tolist()

# ---------------------------------------------------
# 3) Stage B: local reconstruction from selected subsets
# ---------------------------------------------------
def train_local_reconstructor(Xtr_sel, Xtr_full, Xte_sel, Xte_full, epochs=200):
    sel_dim = Xtr_sel.shape[1]
    inputs = keras.Input(shape=(sel_dim,))
    x = layers.Dense(16, activation="relu")(inputs)
    x = layers.Dense(16, activation="relu")(x)
    outputs = layers.Dense(Xtr_full.shape[1], activation="linear")(x)
    model = keras.Model(inputs, outputs)
    model.compile(optimizer="adam", loss="mse")
    model.fit(Xtr_sel, Xtr_full, validation_split=0.1, epochs=epochs, batch_size=16, verbose=0)
    pred = model.predict(Xte_sel, verbose=0)
    mse = mean_squared_error(Xte_full, pred)
    return mse

top_mse = train_local_reconstructor(X_train[:, top_idx], X_train, X_test[:, top_idx], X_test)
next_mse = train_local_reconstructor(X_train[:, next_idx], X_train, X_test[:, next_idx], X_test)

# random subset baseline
rng = np.random.default_rng(7)
rand_idx = rng.choice(n_features, size=top_k, replace=False).tolist()
rand_mse = train_local_reconstructor(X_train[:, rand_idx], X_train, X_test[:, rand_idx], X_test)

# ---------------------------------------------------
# 4) Downstream classification on selected subsets
# ---------------------------------------------------
def clf_acc(Xtr_sel, ytr, Xte_sel, yte):
    clf = LogisticRegression(max_iter=5000)
    clf.fit(Xtr_sel, ytr)
    pred = clf.predict(Xte_sel)
    return accuracy_score(yte, pred)

top_acc = clf_acc(X_train[:, top_idx], y_train, X_test[:, top_idx], y_test)
next_acc = clf_acc(X_train[:, next_idx], y_train, X_test[:, next_idx], y_test)
rand_acc = clf_acc(X_train[:, rand_idx], y_train, X_test[:, rand_idx], y_test)

print("Top-k features:")
print(ranking.head(top_k))

print("\nReconstruction MSE")
print("Top-k subset :", top_mse)
print("Next-k subset:", next_mse)
print("Random-k     :", rand_mse)

print("\nClassification accuracy")
print("Top-k subset :", top_acc)
print("Next-k subset:", next_acc)
print("Random-k     :", rand_acc)
Answer

Expected Results and Notes

Pattern: the top-k subset should usually perform better than the random-k subset, and often better than the next-k subset, especially on reconstruction or classification.

Important discussion point: if the next-k subset also performs reasonably well, why? It suggests redundancy or correlated structure in the data, which connects nicely to the paper’s diversity motivation.
