Assignment

Detailed Assignment Description

Goal. Add Gaussian noise to MNIST and train a denoising autoencoder.

Tasks

  1. Load and normalize MNIST.
  2. Add random Gaussian noise with a chosen noise factor.
  3. Clip values back into [0,1].
  4. Train a Keras autoencoder using noisy images as input and clean images as targets.
  5. Plot 10 examples in three rows: noisy input, clean target, denoised output.
  6. Write 1–2 paragraphs explaining why the network still works even though the input is corrupted.

Optional extension

  • Try multiple noise levels such as 0.2, 0.35, and 0.5 and compare results.

Answer

Reference Answer / Solution

import numpy as np
import matplotlib.pyplot as plt
from tensorflow import keras
from tensorflow.keras import layers

# 1) Load MNIST
(x_train, _), (x_test, _) = keras.datasets.mnist.load_data()
x_train = x_train.astype("float32") / 255.0
x_test = x_test.astype("float32") / 255.0

x_train = x_train.reshape((-1, 28 * 28))
x_test = x_test.reshape((-1, 28 * 28))

# 2) Add Gaussian noise
noise_factor = 0.35
x_train_noisy = x_train + noise_factor * np.random.normal(size=x_train.shape)
x_test_noisy = x_test + noise_factor * np.random.normal(size=x_test.shape)

x_train_noisy = np.clip(x_train_noisy, 0.0, 1.0)
x_test_noisy = np.clip(x_test_noisy, 0.0, 1.0)

# 3) Build denoising autoencoder
inputs = keras.Input(shape=(784,))
x = layers.Dense(128, activation="relu")(inputs)
x = layers.Dense(64, activation="relu")(x)
latent = layers.Dense(32, activation="relu")(x)

x = layers.Dense(64, activation="relu")(latent)
x = layers.Dense(128, activation="relu")(x)
outputs = layers.Dense(784, activation="sigmoid")(x)

dae = keras.Model(inputs, outputs)
dae.compile(optimizer="adam", loss="mse")

# 4) Train noisy -> clean
dae.fit(
    x_train_noisy, x_train,
    validation_split=0.1,
    epochs=20,
    batch_size=256,
    shuffle=True,
    verbose=1
)

# 5) Predict
denoised = dae.predict(x_test_noisy[:10], verbose=0)

# 6) Plot noisy / clean / denoised
plt.figure(figsize=(14, 6))
for i in range(10):
    ax = plt.subplot(3, 10, i + 1)
    plt.imshow(x_test_noisy[i].reshape(28, 28), cmap="gray")
    plt.axis("off")

    ax = plt.subplot(3, 10, i + 11)
    plt.imshow(x_test[i].reshape(28, 28), cmap="gray")
    plt.axis("off")

    ax = plt.subplot(3, 10, i + 21)
    plt.imshow(denoised[i].reshape(28, 28), cmap="gray")
    plt.axis("off")

plt.suptitle("Top: noisy | Middle: clean target | Bottom: denoised output")
plt.tight_layout()
plt.show()
