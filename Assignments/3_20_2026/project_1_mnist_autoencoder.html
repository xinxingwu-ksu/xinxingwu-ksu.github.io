Assignment

Detailed Assignment Description

Goal. Build and train a dense autoencoder on MNIST handwritten digits.

Your tasks

  1. Load MNIST with keras.datasets.mnist.load_data().
  2. Normalize pixel values to the range [0,1].
  3. Flatten each image from 28×28 into a vector of length 784.
  4. Build an encoder and decoder in Keras. Use a bottleneck of size 32.
  5. Train the model with MSE loss.
  6. Plot 10 original images and their reconstructions.
  7. Change the bottleneck to 16 and compare the test MSE.
  8. Write a short reflection explaining why a smaller bottleneck usually loses more detail.

Deliverables

  • Python file or notebook (JupyterLab or Google Colab)
  • One figure with original vs reconstructed images
  • One table reporting bottleneck size and test MSE
  • A 1-paragraph reflection

Answer

Reference Answer / Solution

import numpy as np
import matplotlib.pyplot as plt
from tensorflow import keras
from tensorflow.keras import layers

# 1) Load and normalize MNIST
(x_train, _), (x_test, _) = keras.datasets.mnist.load_data()
x_train = x_train.astype("float32") / 255.0
x_test = x_test.astype("float32") / 255.0

x_train = x_train.reshape((-1, 28 * 28))
x_test = x_test.reshape((-1, 28 * 28))

# 2) Build a simple dense autoencoder
input_dim = 784
latent_dim = 32

inputs = keras.Input(shape=(input_dim,))
encoded = layers.Dense(128, activation="relu")(inputs)
encoded = layers.Dense(64, activation="relu")(encoded)
latent = layers.Dense(latent_dim, activation="relu", name="latent")(encoded)

decoded = layers.Dense(64, activation="relu")(latent)
decoded = layers.Dense(128, activation="relu")(decoded)
outputs = layers.Dense(input_dim, activation="sigmoid")(decoded)

autoencoder = keras.Model(inputs, outputs, name="mnist_autoencoder")
encoder = keras.Model(inputs, latent, name="mnist_encoder")

autoencoder.compile(optimizer="adam", loss="mse")

# 3) Train
history = autoencoder.fit(
    x_train, x_train,
    validation_split=0.1,
    epochs=20,
    batch_size=256,
    shuffle=True,
    verbose=1
)

# 4) Evaluate
test_mse = autoencoder.evaluate(x_test, x_test, verbose=0)
print("Test MSE:", test_mse)

# 5) Visualize original vs reconstructed images
recon = autoencoder.predict(x_test[:10], verbose=0)

plt.figure(figsize=(14, 4))
for i in range(10):
    ax = plt.subplot(2, 10, i + 1)
    plt.imshow(x_test[i].reshape(28, 28), cmap="gray")
    plt.axis("off")
    ax = plt.subplot(2, 10, i + 11)
    plt.imshow(recon[i].reshape(28, 28), cmap="gray")
    plt.axis("off")
plt.suptitle("Top row: original | Bottom row: reconstruction")
plt.tight_layout()
plt.show()

# 6) Optional comparison with a smaller bottleneck
for smaller_dim in [16]:
    inputs2 = keras.Input(shape=(input_dim,))
    z = layers.Dense(128, activation="relu")(inputs2)
    z = layers.Dense(64, activation="relu")(z)
    z = layers.Dense(smaller_dim, activation="relu")(z)
    z = layers.Dense(64, activation="relu")(z)
    z = layers.Dense(128, activation="relu")(z)
    outputs2 = layers.Dense(input_dim, activation="sigmoid")(z)
    model2 = keras.Model(inputs2, outputs2)
    model2.compile(optimizer="adam", loss="mse")
    model2.fit(
        x_train, x_train,
        validation_split=0.1,
        epochs=10,
        batch_size=256,
        shuffle=True,
        verbose=0
    )
    mse2 = model2.evaluate(x_test, x_test, verbose=0)
    print(f"Test MSE with latent_dim={smaller_dim}:", mse2)

Expected Results and Notes

Outcome: You should see clearly recognizable reconstructed digits. With a bottleneck of 32, reconstructions are usually better than with a bottleneck of 16.

Loss range: the exact MSE depends on random initialization, number of epochs, and hardware, but the final test MSE should usually be substantially lower than the starting loss.

Reminder - Common mistakes: forgetting normalization, using the wrong output activation, not flattening the images, or comparing images before reshaping them back to 28×28.
